# Versioneer

This is a high performance project dependency scanner and tracker. It's goals:

- Fast scanning of project dependencies
- Accurate tracking of changes to dependencies
- Easy integration with build systems
- Support for multiple programming languages and build systems
- Minimal configuration required
- Open source and actively maintained

Versioneer is designed to be fast and efficient, while also being easy to use and integrate into existing workflows. Whether you're working on a small project or a large codebase, Versioneer can help you manage your dependencies and keep your builds running smoothly.

## Key Requirements

Data points: Number of projects, number of dependencies, frequency of changes, build times, est. last install/update time, find all projects with a specific dependency, list dependencies for a library over time, track changes to dependencies over time, identify outdated dependencies, identify potential security vulnerabilities in dependencies, support for multiple programming languages and build systems, easy integration with build systems, minimal configuration required.
